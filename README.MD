WORKSPACE-BASICS

1. Описание 
Репо несет исключительно учебный характер, где показаны базовые настройки репозитория и проекта. 
Базовая структура проекта: 
- файлы конфигурации, 
- .gitignore, 
- структура каталогов проекта, 
- инициализация git.

2. Запуск проекта
- Скопировать репозиторий к себе в удобное место. Например: C:/dev/workspace-basics
- Открыть терминал внутри репозитория в корневом каталоге и выполнить команду: python src/main.py
